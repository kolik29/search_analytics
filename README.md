# Search Analytics

## Порядок запуска

Потребуются Node.js 18 или новее и совместимая версия npm. Выполняйте команды из корня проекта.

1. Установите зависимости:

   ```bash
   npm ci
   ```

2. Соберите проект:

   ```bash
   npm run build
   ```

3. Сохраните выгрузку БД `sgm_search_analitics` в файл `dist/result.csv` в формате CSV с заголовками колонок.

4. Запустите анализ:

   ```bash
   npm start -- ./dist/result.csv
   ```

## Параметры `--from` и `--to`

- `--from` — начало периода включительно.
- `--to` — конец периода включительно.

Параметры можно использовать вместе или по отдельности. Без них анализируется весь CSV.

Даты задаются в формате `YYYY-MM-DD` или `DD.MM.YYYY`. Для `--from` используется начало дня (`00:00:00`), для `--to` — конец дня (`23:59:59`), в UTC.

```bash
npm start -- ./dist/result.csv --from 2026-07-01 --to 2026-07-31
npm start -- ./dist/result.csv --from 01.07.2026
npm start -- ./dist/result.csv --to 31.07.2026
```
